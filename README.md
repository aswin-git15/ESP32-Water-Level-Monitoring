# ESP32-Based Smart Water Level Monitoring and Alert System

## Project Description

This project is an ESP32-based water level monitoring and alert system. An HC-SR04 ultrasonic sensor is used to measure the water level in a tank. The measured level is calculated as a percentage and displayed on an OLED display.

The system provides different alerts based on the water level:

- Below 50% – Normal condition
- 50% to 79% – Green LED blinks
- 80% or above – Red LED turns ON and buzzer is activated

## Components

- HC-SR04 Ultrasonic Sensor
